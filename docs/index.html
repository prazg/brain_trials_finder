      How the match score works

      The score is a sort order built from the published record, not an eligibility decision. It starts at 0, is capped between 0 and 100, and every adjustment is shown on the card.

      +30Title or condition names the chosen diagnosis (+14 if it is neuro-oncology under a wider term)
      +12 / +8Phase 3 / Phase 2
      +10At least one site open in the chosen region
      +8Eligibility text matches the disease setting (recurrent or newly diagnosed); +6 if “recurrent” is in the title
      +5Surgical component, when “fit for further surgery” is ticked
      +4Each keyword found in the title or eligibility text
      −30Patient is younger than the minimum age or older than the maximum
      −25Eligibility text excludes prior bevacizumab, when that box is ticked
      −15Eligibility text asks for a better performance status than entered (KPS is converted to ECOG approximately: 100 → 0, 80–90 → 1, 60–70 → 2, 40–50 → 3)

      Eligibility text is free prose and the matching is simple pattern-matching, so read the criteria on the register before drawing any conclusion.

      This is not medical advice. It is a search aid over public trial registers. Eligibility is decided by the trial team, not by this page — always confirm with the treating clinician and the trial contact before acting on anything here.

      Sources: ClinicalTrials.gov (US NIH, queried live) · ISRCTN registry (UK, queried live) · EU CTIS (loaded from a snapshot, because CTIS blocks direct browser requests) · WHO ICTRP (snapshot; supplies CTRI India, ChiCTR China, JPRN Japan, ANZCTR, DRKS and other national registries, none of which permit direct browser requests). Each snapshot shows its build date above the results. Registers overlap; the same trial can appear more than once under different identifiers.
